## ⚙️ Setup Instructions

Run this project locally:

```bash
# Clone repository
git clone https://github.com/akashgupta0123/akash-portfolio.git

# Navigate to project folder
cd akash-portfolio

# Install dependencies
npm install

# Run development server
npm run dev
```

Open:

```text
http://localhost:3000
```

or

```text
http://localhost:5173
```

depending on your Vite configuration.
